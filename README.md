# Placement Portal Application V2

## Project Overview

This project is developed as part of the Modern Application Development II (MAD-II) course.

The Placement Portal Application is a web application that connects students, companies, and administrators during campus placement activities.

## Technology Stack

- Frontend: Vue.js
- Backend: Flask
- Database: SQLite
- ORM: SQLAlchemy
- Authentication: JWT
- Cache: Redis
- Background Jobs: Celery
- Version Control: Git & GitHub

## Features

- Student Registration & Login
- Company Registration & Approval
- Admin Dashboard
- Job Posting
- Job Applications
- Placement Tracking
- Reports & Analytics
